# 📊 Superstore Sales Analysis Dashboard

An end-to-end Excel Data Analytics project focused on analyzing Superstore sales performance, identifying business trends, and generating actionable insights through interactive dashboards and data-driven analysis.

---

# 🚀 Project Overview

This project was built using Microsoft Excel to perform complete sales analysis on Superstore data.  
The project includes:

- Data Cleaning & Preparation
- Outlier Detection
- Descriptive Statistical Analysis
- Product Performance Analysis
- Regional Sales Analysis
- Business Insights Generation
- Interactive Dashboard Visualization

The dashboard helps understand sales performance, profit trends, customer behavior, and regional business growth.

---
